# GitHub Analyzer

## O que faz

Busca na API do GitHub os dados de um usuário e mostra o username e a quantidade de repositórios públicos.

## Como rodar

Requisito: Node.js 18 ou mais novo.

```
cd backend/src
node index.js Santosx-7
```

Saída:

```
Santosx-7, tem 7 repositórios públicos
```

## Stack

- Node.js
- JavaScript
- API REST do GitHub
